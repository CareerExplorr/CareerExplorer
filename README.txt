Career Skill Tree - static website

Upload this whole folder (index.html + the data folder) to any static host. No server or database needed.

Fastest (about 2 minutes, free):
  1. Go to https://app.netlify.com/drop
  2. Drag this folder onto the page.
  3. You get a public link right away. Sign up (free) to keep it and rename it.

Other free options: GitHub Pages, Cloudflare Pages, Vercel. Upload the same folder.
To test on your computer first: open a terminal in this folder, run  python -m http.server 8000,
then open http://localhost:8000
